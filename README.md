## How to Compile and Run

Open the required task folder in the terminal.

Compile a Java file:

```bash
javac FileName.java
```

Run the compiled program:

```bash
java ClassName
```

Replace `FileName` with the Java source filename and `ClassName` with the class containing the `main` method. Some programs may require compiling multiple Java files together.
